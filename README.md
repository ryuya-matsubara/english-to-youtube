# English Before YouTube

YouTubeを見る前に、英語を1問だけ練習するスマートフォン向けWebサイトです。

## Webサイト

GitHub Pages を有効にすると、次のURLから利用できます。

**https://ryuya-matsubara.github.io/english-to-youtube/**

## 使い方

1. 画面に出る日本語を、英語でどう言うか声に出して考える。
2. **「答えを見る」**を押すと、自然な米語の言い方とIPA（国際音声記号）が表示される。
3. 必要に応じて**「発音を聞く」**を押してブラウザの読み上げで確認する。
4. **「次の問題」**で続けるか、解答表示後の**「YouTubeへ進む」**でYouTubeを開く。

## 収録内容

- 日常生活：40問
- ビジネス：30問（会議、タスク管理、システム運用、障害対応など）
- 海外旅行：30問（空港、ホテル、レストラン、交流など）
- 合計：**100問**

カテゴリを切り替えて出題でき、選択したカテゴリの問題はランダム順で、すべて出題するまで重複しません。1周したら新しいランダム順で繰り返します。カテゴリの選択はブラウザに保存されます。

## GitHub Pages の公開設定（最初の1回だけ）

このリポジトリのGitHub画面で以下を設定します。

1. **Settings → Pages** を開く。
2. **Build and deployment → Source** で **Deploy from a branch** を選択する。
3. **Branch** に **main**、フォルダに **/(root)** を選び、**Save** を押す。
4. 上記のWebサイトURLを開く。

※ GitHub Pagesの公開URLが利用可能になるまで、GitHub側のデプロイ処理が必要な場合があります。リポジトリ公開後でも、Pages設定が有効とは限りません。

## 技術構成

- HTML / CSS / Vanilla JavaScript の静的サイト
- サーバー、APIキー、ビルド手順、外部JavaScriptライブラリは不要
- IPAは一般的なアメリカ英語の発音を目安として記載（話者・地域・会話速度で変化します）
- 読み上げには Web Speech API を使用（端末の声質や対応状況に依存）
- YouTubeリンクは答えを表示するまで非表示
- モバイルのSafari/Chromeで使えるレスポンシブデザイン

## 編集

問題文と解答は `index.html` の `question-data` に、`カテゴリ|日本語|英語|IPA` の順で1行ずつ保存されています。
