# English Before YouTube

YouTubeを見る前に英語を1問だけ練習する、シンプルなスマホ向けWebサイトです。

**Webサイト：** https://ryuya-matsubara.github.io/english-to-youtube/

## 使い方

1. 開くと日本語の問題が1つだけ表示されます。
2. 英語で言ってみてから「答えを見る」を押します。
3. 自然な英語と発音記号（IPA）が表示されます。「発音を聞く」も利用できます。
4. 「次の問題」で続けるか、「YouTubeへ進む」でYouTubeを開きます。

## 問題の内訳

- 日常生活：40問
- ビジネス：30問
- 海外旅行：30問

合計100問をランダムな順番で出題します。100問を一周するまで同じ問題は出ません。カテゴリ切り替えや進捗表示などを設けず、最初の画面には日本語の問題と解答ボタンだけを表示します。

## 公開設定

GitHubの **Settings → Pages** で **Deploy from a branch**、ブランチ **main**、フォルダ **/(root)** を設定してください。公開設定がすでに有効なら変更は不要です。

## 技術

静的HTML/CSS/JavaScriptのみ。音声はブラウザのWeb Speech API（英語音声の品質はデバイス依存）。IPAは米語の一般的な発音目安です。
